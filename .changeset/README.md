# Changesets

Every PR that changes icons or packages adds a changeset: `npm run changeset`.

- **patch** — fixes to existing icon shapes, metadata, docs
- **minor** — new icons, new props or outputs
- **major** — removing or renaming an icon without an alias, changing a prop's meaning

`@ottomind-ai/icons` and `@ottomind-ai/icons-react` always release with the same version.
